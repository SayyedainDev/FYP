# Lecture Notes Feature - Quick Start Guide

## For Doctors/Dentists

### Accessing Lecture Notes
1. Login to your account
2. Look for **"Lecture Notes"** in the left sidebar (📚 icon)
3. Click to open the management screen

### Uploading Lecture Notes

**Step 1: Go to Upload Tab**
- Click "Upload Notes" tab at the top

**Step 2: Fill in Details**
- **Title**: Enter a descriptive title (e.g., "Orthodontics Chapter 3")
- **Description**: Add what this note is about
- **Tags**: Add searchable tags (comma-separated, e.g., "orthodontics, chapter3")

**Step 3: Select File**
- Click the upload area to select a file
- Supported formats:
  - Documents: PDF, DOCX, DOC, PPTX, TXT
  - Images: JPG, JPEG, PNG
  - Videos: MP4
- Maximum size: **25 MB**

**Step 4: Upload**
- Click "Upload File" button
- Wait for upload to complete
- You'll see a success message

### Managing Your Notes

**View All Notes**
- Click "My Notes" tab
- All your uploaded notes appear in a grid

**Search Notes**
- Use the search bar to find notes by title, description, or tags

**View Note Details**
- Click any note card to see full details
- Information shows:
  - File type
  - Description
  - File size
  - Tags
  - View count

**Delete a Note**
- Click the three-dot menu on a note card
- Select "Delete"
- Confirm deletion

## Creating Quizzes with Lecture Notes

### Step 1: Start Quiz Creation
1. Go to **"AI Quiz"** in sidebar
2. You'll see three sections:

### Section 1: Upload New File (Blue)
- Upload a file directly for this quiz only
- File is stored separately from your lecture notes library
- Click upload area to select

### Section 2: Select Existing Notes (Orange)
- See all your previously uploaded lecture notes
- Click to select/unselect notes (multi-select supported)
- Selected notes will be available when generating questions
- Shows note count

### Section 3: Additional Notes (Purple)
- Upload extra materials for this specific quiz
- Optional - only use if you need quiz-specific files
- These aren't saved to your lecture notes library

### Step 4: Continue
- After selecting notes/files, enter quiz title
- Click "Next: Configure Quiz"
- Continue with normal quiz configuration

## Tips & Best Practices

✅ **DO**
- Use descriptive titles for easy searching
- Add multiple tags for better organization
- Upload notes before creating multiple quizzes
- Group related materials with similar tags
- Check file size before uploading (max 25MB)

❌ **DON'T**
- Upload corrupted files
- Use very long file names (keep under 100 chars)
- Upload files larger than 25MB
- Upload duplicate notes (search first to check)

## Troubleshooting

**File Won't Upload**
- Check file size (max 25MB)
- Verify file format is supported
- Check internet connection
- Try a different file if it's corrupted

**Can't Find Note**
- Use search feature with keywords
- Check tags you assigned
- Look in "My Notes" tab

**Notes Not Appearing in Quiz**
- Refresh the page
- Make sure you're selecting from the orange section
- Check if notes were successfully uploaded

**Upload Takes Too Long**
- Large files take more time
- Reduce file size if possible
- Use a faster internet connection

## Notes Storage

- Files are securely stored in the cloud
- Only you can access your notes
- Notes are available for all future quizzes
- Deleted notes cannot be recovered
